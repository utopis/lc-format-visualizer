## How the engine should use this
1. **Pick format → angle → script**: angle comes from LC review mining / motivators (Meta's Q4 playbook: build each ad from a customer motivator — 3 motivators × 3 hooks × 9:16/4:5/static; see [discovery/Peter_Quadrel.md](https://x.com/Peter_Quadrel)).
2. **Diversify Entity IDs**: Meta clusters visually similar ads; a new *format* (not a new hook) is what creates a new Entity ID. Rotate formats 04/05/09/14/26/31/32 against the same angle. Use the @williamkast_ matrix: production format (founder, UGC, static, podcast, AI) × framework (DITL 45, 3 reasons 39, old me/new me, phone call 26, us vs them 16) = 25 concepts from one message.
3. **Diagnose before producing**: if the top 5 spenders are 90+ days old, the account needs new reasons-to-buy (angles), not more variants (@adamtaylorl).
4. **Measure in Omni**: every asset `utm_content=<format-file-number>-<concept>-<variant>`; weekly roll-up of new-customer revenue by format.
5. **Creator engine**: run F43 (Hudson Method swarm) as the supply of real-creator assets; use F53 (AI UGC outlier-remake lab) to find angles cheaply on organic first, then brief winners to real creators.
6. **Quick map by funnel**: TOF = 04, 05, 08, 14, 26, 28, 29, 30, 31, 38, 39, 43, 54, 55, 56, 100, 102, 103, 105, 106, 109, 110, 111, 112; MOF = 09, 11, 108, 16, 32, 34, 35, 36, 40, 48, 57, 58, 59, 61; BOF/retargeting = 17, 37, 25, 60, 62, 64, 75, 86, 87, 89, 90; seasonal = 65.
