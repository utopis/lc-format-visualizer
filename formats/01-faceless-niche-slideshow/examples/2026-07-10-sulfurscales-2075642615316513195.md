## Full text

> this is how app founders are scaling to $10k/mo with slideshows.
> 
> you'll need to spend 4-6 hours on this on just one day, and get content for 2+ months without touching it.
> 
> a great format to copy is this:
> 
> content, content, content, content, ad warmup, app push
> 
> the idea is to make slideshow posts that feel like actual content, then only bring in the app/saas shoutout near the end
> 
> so instead of posting obvious ads, the account posts stuff that looks like normal tiktok slideshow content:
> 
> lifestyle takes, niche opinions, curiosity hooks, "things nobody tells you," etc. the images on the post are an example
> 
> find hundreds of lifestyle/travel/interior-style visuals on pinterest / google
> 
> use ai to generate dozens of similar captions that basically say the same thing
> sneak the app into the content without making it look too promotional
> posting across multiple tiktok accounts
> one of my top posts on tiktok got 1.2M views like this: PROOF
> 
> i set up a workflow with:
> 
> claude code (using terminal. it's actually more powerful than claude app, you don't need to be a dev to use this, just a few scary commands you copy and paste). HIGHLY RECOMMENDED to not skip.
> 
> socialclaw (cli tool to schedule to social media. you install via sudo npm install -g socialclaw and claude code can schedule posts for you)
> openai api or any other image api (e.g gemini api, any other good image model). we'll need this later.
> HERE'S HOW TO SPEND THESE 4-6 HOURS:
> 
> 0-60 minutes —> research competitors. is your app a note taker? search note taker on tiktok and just view all top posts, screenshot all of them. do NOT SKIP.
> 
> keep notes of what they write in captions/text over slides. just copy paste somewhere. save for later.
> 
> hour 1 - hour 3 —> go to pinterest. remember those screenshots you took? find similar reference images on pinterest. spend 2 hours doing this.
> 
> figure out what slide 1 should look like. figure out what slide 2 should look like. etc.
> download a few images for each slide type from pinterest. name them as slide_1_1.jpg etc.
> 
> hour 4 —> now, not all pinterest photos are allowed to be reposted.
> in that case, ask claude code to see the images and use openai image api to generate 100x copies of those images with slight variations but keeping the same vibe!
> now you'll have for example 5 slide types x 100 variations = 500 images. do less to start maybe.
> 
> hour 5 —> remember the notes of captions you took? ask claude now to overlay caption variations over all those images and tell it "here are how the captions you generate for our posts should look like [paste caption list from competitors]. copy the best ones".
> claude code then:
> 
> comes up with slideshow angles
> 
> writes the slide-by-slide text
> keeps the early slides content-first
> adds the app/product later in the slideshow
> claude will generate captions and it can actually overlay text over images (that's why i told you to use claude code before). it uses ffmpeg library (like all video/image software) to overlay text automatically.
> 
> ask claude to schedule 2x posts a day for each account. after that socialclaw handles the actual posting side:
> 
> uploads
> 
> -> account handling
> -> scheduling
> -> publishing
> 
> THAT'S IT. YOU'RE DONE. you now have months worth of content, it's all scheduled to be posted.
> 
> the reason this is useful is that this strategy is insanely repetitive
> 
> 10 accounts posting 2x posts a day = 20 posts a day.
> 
> 90% of posts go under ~5,000 views, most even staying under 300 views.
> 
> a few posts on each account get 50K - 500K views (some even 1M+)
> 
> format stays the same, just fresh similar content. e.g. same tokyo photo, just a different variation.
> 
> 0.1-2% of viewers actually download the app depending on your content
> 
> multiply this by 30 days and you get plenty of traffic
> once the workflow is set up, it becomes much easier to run this like a system instead of making random one off posts.
