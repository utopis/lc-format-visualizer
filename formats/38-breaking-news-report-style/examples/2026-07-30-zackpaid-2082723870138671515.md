> we produce a FULL 20-creative meta ads batch in 5-8 hours
> 
> the human production pipeline doing the same thing takes 8-13 days.
> 
> here's the 4-stage stack we run end to end:
> 
> stage 1 is research, never ideation. opus 4.8 in cowork mode with the meta MCP connected. it pulls the last 14 days of live account data, aggregates by hook category and format type, identifies which buying triggers are winning and which have never been tested.
> 
> then it scans the meta ad library for competitor ads running 30+ days, reverse-engineers the buying trigger underneath each one, and flags gap angles nobody in the category is testing.
> 
> output: a prioritized angle brief with 20 angles ranked by priority score. every creative in the batch gets built from this brief.
> 
> we don't make anything up.
> 
> stage 2 is production through the higgsfield MCP. seedance 2.0 for video, chatgpt images 2.0 for statics.
> 
> the workflow starts with a real photo every time: the founder, the product, the office. chatgpt images 2.0 enhances the reference. seedance 2.0 turns the enhanced stills into finished 15-second videos with synced audio.
> 
> for AI UGC: seedance 2.0 generates character-consistent video in the native phone-camera aesthetic. same "person" across multiple clips, different settings, different scripts.
> 
> for native formats: chatgpt images 2.0 produces pixel-accurate iMessage threads, apple notes, google search results, breaking news screenshots. each one matched to a specific angle from the brief.
> 
> stage 3 is copy refinement. sonnet 5 with meta MCP context reviews every script against what the algorithm is currently rewarding in the account. anti-slop audit catches anything generic, hedged, or AI-sounding. every line gets read out loud. anything that sounds like recitation gets rewritten.
> 
> stage 4 is launch and iteration through fable 5. 72-hour hands-off after launch. day 5-7 evaluation. winners move to scaling. losers get logged. fable 5 monitors every 4 hours for fatigue and triggers format rotation automatically.
> 
> the feedback loop: performance data from this batch feeds directly into stage 1 of the next cycle.
> 
> four tools, four stages, a 2-week refresh cycle.
> 
> each batch is built on the data from every batch before it.
> 
> so the account compounds instead of resetting every month.
>
