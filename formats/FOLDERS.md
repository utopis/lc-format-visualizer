# Format folders

Each format is a folder: `README.md` (playbook) · `BOT.md` (plug-in generator brief) · `STAGES.md` + `stages/` · `brands/louise-carter.md` · `examples/` (every X post we hold) · `meta.json`.

To add a new format: copy any folder, rename to the next `NN-slug`, rewrite README.md, then run `python3 _tools/folderize_formats.py` and `python3 _tools/build_visualizer.py`.
