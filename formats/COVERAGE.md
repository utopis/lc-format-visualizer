# Funnel coverage: where every format sits, and what is missing

Every format in this library, placed on the funnel. Use it to audit Louise Carter's funnel: which stages have plenty of proven formats, which have thin evidence, and which formats LC has not produced or tested yet.

**How to read it**

- **Example match**: `exact` the featured example is this format · `close` it is a near relative · `proxy` the nearest real thing we could find · `weak` a breakdown post rather than an ad.
- **Real examples**: posts collected for the format (curated + gallery). Under 5 means the format is thinly evidenced; look for more before betting budget on it.
- **LC status**: how far Louise Carter has taken the format (Find → Deep research → Concepts → Production → Test → Scale → Learnings).
